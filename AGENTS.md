# Instruções para agentes

**Para aplicar a identidade visual byescaleira num projeto** (web, landing page, slides, app iOS, iPadOS, macOS, tvOS, Android ou Windows), siga [skills/byescaleira-visual-id/SKILL.md](skills/byescaleira-visual-id/SKILL.md).

Onde a skill escreve `${CLAUDE_PLUGIN_ROOT}`, leia a raiz deste repositório. Os valores ficam em [tokens/tokens.json](tokens/tokens.json).

**Para mudar a identidade,** siga [CLAUDE.md](CLAUDE.md).
